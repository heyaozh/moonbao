深夜天文台

安静、克制、有点贵。星空是墨蓝到近黑的深空，星座用极细的金色线条勾出来，券是一张牛皮纸质感的旧车票。整个 app 像一本精装的星图册。

色彩

深空墨蓝为底，旧金为唯一强调色，纸色只出现在券上。

字体

标题宋体（Noto Serif SC），拉丁字用 Cormorant 斜体做标签；正文黑体。数字用等宽。

动效

星星慢速呼吸；滑动时前后景轻微视差；兑现是一条细长的流星，落地变成票根。克制，不弹跳。

最适合承载

时间胶囊实物 NFC 卡30 欧定价 卡面就是这张星图，天然成套。

优点 / 风险

  • 高级感直接支撑一次性卖贵
  • 美术量小：线条和点，程序化生成星座就够
  • 深色底让「远星 / 近星」的层次最清楚
  • 偏冷，「奶茶好喝吗」这种日常互动放进去会显得过于正式
  • 用户多在白天打开，全黑界面在阳光下不好看

纸上星空

像两个人一起做的手账。夜空是靛蓝色的纸，星星是墨点和四角星贴纸，星座用虚线手绘。券是白卡纸加虚线边和一枚红色印章，字是手写体。所有东西都像是能拿在手里的。

色彩

靛蓝纸 + 米白卡纸，印章红是唯一的强调色。日间模式可以整页切成米白纸。

字体

手写体（马善政 / Caveat）只用于券和标签，正文仍是黑体，避免通篇手写难读。

动效

贴纸式：新星「啪」地贴上去带一点弹性；兑现是印章盖下去的动作；胶囊封存像把信塞进信封。

最适合承载

情侣小店问句动态和好券 日常互动的温度最对。

优点 / 风险

  • 温暖、亲密，最符合「不像账本」的原则
  • 券本身就是好看的东西，用户愿意截图分享
  • 日间可以是纸色界面，解决白天打开的问题
  • 容易滑向「可爱」的套路，需要克制贴纸数量
  • 手写体的多语言支持要单独处理（中英各选一款）
  • 纸质感做粗糙会显廉价，纹理和阴影要调很久

像素小宇宙

把「这是我们俩的小游戏」直接画成游戏。8-bit 的星星、道具栏一样的商店、像素金币，券是背包里的物品，兑现有音效。以后的电子宠物在这个世界里是最自然的。

色彩

深紫底，金黄 + 冰蓝两个高饱和强调色，像素游戏的经典配法。

字体

拉丁用 Press Start 2P，中文用站酷庆科黄油体或自绘像素字；正文可退回黑体保证可读。

动效

帧动画：星星四格闪烁、券掉进背包、金币跳一下。逐帧做，不用缓动曲线。

最适合承载

电子宠物币和勋章限量 / 盲盒 游戏化元素在这里不需要解释。

优点 / 风险

  • 辨识度最高，最容易在社交平台传播
  • 像素资产小而可复用，长期美术投入最可控
  • 「收藏币 / 勋章 / 盲盒」的心理在游戏语境里完全成立
  • 和「时间胶囊 + 实物卡 + 30 欧」的郑重感不搭，两条线要分开处理
  • 受众偏窄：不玩游戏的一方可能觉得幼稚
  • 像素风做得半吊子比任何风格都难看，要真的懂像素美术

柔光星云

黄昏色的星云渐变、磨砂玻璃的卡片、大圆角。看起来像一个精心做的原生 iOS app，任何人第一眼都觉得舒服、现代、安全。

色彩

靛蓝到珊瑚的黄昏渐变，白色玻璃层，没有单独的强调色，靠渐变本身出彩。

字体

系统字（苹方 / SF），加粗做层级。不引入个性字体。

动效

iOS 原生那套：弹簧过渡、卡片上滑、模糊变化。用户零学习成本。

最适合承载

快速上线大众接受度 Flutter / SwiftUI 实现成本最低。

优点 / 风险

  • 开发最快，几乎不需要美术
  • 不冒犯任何人，配对时被拉的一方不会被风格劝退
  • 这正是现在 AI 生成设计和大批新 app 的默认长相，毫无记忆点
  • 渐变星云和「星座币 / 摘星」的线条语言不太兼容，星星会被糊掉

我的推荐：A 的天空，B 的手

夜空用 A 的语言：深空底、极细金线、程序化星座，这是「远星 = 胶囊」这条长期线的郑重感来源，也是实物 NFC 卡面的直接素材。落到手里的东西全部用 B 的语言：券是虚线边的卡纸票、兑现是盖章、和好券是手写的一句话、胶囊封存是塞进信封。两种语言在「天上 / 手里」这条边界上分开，不会打架。

日间模式按 B 处理：大厅在白天是米白纸色的「白昼星空」，星星变成淡墨点，晚上才变深空。这同时解决了 A 的白天问题和「两地天空」的可能性。

C 不建议做主视觉，但它的两样东西值得偷：币和勋章的「收藏品」质感可以用小尺寸的像素或版画风来做，让它们在整个界面里有一点点不同的材质；将来的宠物也可以是这种风格的小东西。D 建议只作为兜底：如果阶段 0 的概念图做不出 A + B 的质感，先用 D 上线验证机制，再换皮。
