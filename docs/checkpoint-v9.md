## 秘密彩蛋怎么用（V9-E）
1. `npm run egg -- salt`：生成盐，写进 `.env`（不提交）。
2. `npm run egg -- add`：暗号隐藏输入两遍 → 回复（可用 `{{moon}}` / `{{user}}`）→ 表情（默认 heart）→ 动作（默认 bounce）。仓库里只多一条哈希 + base64 回复。
3. 重启 `npm run dev:server`；把暗号告诉爱人。他们打字或说出那句话（大小写、空格、标点都不算数），它就惊讶 → 爱心眼 + 弹跳 + 冒 ♥ → 亮起 → 用远方流星写回复。
4. `npm run egg -- test` 可以自己试一句会不会命中；`list` 只列 id；`remove <id>` 删。
5. 片子 `snaps/v9/secret.mp4` 里的「暗号」只是示意（`I'm here, 小月亮 ✦`），不是真的。
